# chart-sensei-site

iOSアプリ「チャート分析の先生」の公開ページ（GitHub Pages）。

- サポート: `index.html`
- プライバシーポリシー: `privacy.html`
- 利用規約: `terms.html`

## 重要

- **このリポジトリ名を変更しない。** GitHub Pagesはリネーム後にリダイレクトを張らないため、
  App Store掲載URL・アプリ内リンクがすべて切れる。
- App Store提出前に `[...]` の差し込み箇所をすべて埋めること
  （提供者名・公開日・お問い合わせ用メールアドレス）。
- 本文の記述はアプリの実挙動と一致していなければならない。仕様変更時は本リポジトリも更新する
  （波及先リスト: chartAnalyzer リポジトリの plans/design-principles.md「事実の散り」）。
